# Mouse Game
This project aims at making a windowless idle game, like *Bongo Cat*, where the user accrues points correlating to distance traveled with the mouse.

The points directly correlate to the real distance travelled by the users mouse movements. How we'll compute this is still unknown, but if we are able to know the pixel density of the screen we should be able to correlate that with the mouse movement to generate real distance travelled.

Stack: *Rust, wgpu*
